Tip · edición #003

Limpieza eficiente con Pandas

Python 
import pandas as pd
# Eliminar filas donde todos los valores son nulos
df = df.dropna(how='all')
# Imputar valores nulos con la mediana
df['ventas'] = df['ventas'].fillna(df['ventas'].median())
# Convertir tipos de datos en bloque
df = df.astype({'id': 'int', 'precio': 'float'})

Usa estas operaciones vectorizadas para limpiar datasets masivos antes de enviarlos a modelos de ML; evitan los bucles lentos y reducen drásticamente el tiempo de preprocesamiento. Ver edición →

Tip · edición #002

Limpieza rápida con Pandas

Python 
import pandas as pd
# Eliminar duplicados y rellenar nulos
df = df.drop_duplicates()
df['valor'] = df['valor'].fillna(df['valor'].mean())
# Convertir a minúsculas para estandarizar categorías
df['categoria'] = df['categoria'].str.lower().str.strip()

Usa este snippet al inicio de cualquier pipeline para asegurar la integridad básica de tus datos antes de modelar. Ver edición →

Tip · edición #001

Limpieza rápida con Pandas

Python 
import pandas as pd
# Eliminar filas con valores nulos y normalizar nombres de columnas
df = df.dropna()
df.columns = [c.lower().replace(' ', '_') for c in df.columns]
# Convertir fechas de formato objeto a datetime
df['fecha'] = pd.to_datetime(df['fecha'])

Usa este bloque al inicio de cualquier script para estandarizar tus DataFrames y evitar errores de tipo en análisis posteriores. Ver edición →
